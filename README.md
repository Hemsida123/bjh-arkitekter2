# BJH Arkitekter – komplett nettsted

14 HTML-sider, lokal CSS, JavaScript, skrifter og prosjektbilder. Ingen installasjon eller byggetrinn kreves.

## Publisere på GitHub Pages
1. Pakk ut ZIP-filen.
2. Last opp alt innholdet til hovedmappen i GitHub-repositoriet. index.html skal ligge direkte der, sammen med styles.css, app.js, fonts.css og assets-mappen.
3. Velg Settings > Pages > Deploy from a branch > main > / (root).
4. Bruk adressen GitHub Pages viser når publiseringen er ferdig.

Ikke last opp selve ZIP-filen. Behold filnavn og mappestruktur. Alle lokale lenker er relative, slik at siden også fungerer i en GitHub-undermappe.

## Kontakt
Skjemaet åpner et e-postutkast i brukerens e-postprogram. Det sender eller lagrer ikke meldinger på en server. Telefon- og e-postlenker fungerer direkte.

## Bilder og innhold
Prosjektbildene er BJHs egne arkitekturvisualiseringer fra bjh-ark.no, ikke fotografier. Det er ikke lagt inn påstander om oppføringsår, arealer, priser eller kundeomtaler uten kildestøtte. Se SOURCES.md for opprinnelse. Godkjenning av bilder og endelig innhold må avklares med bedriften før offisiell overtakelse.

## Søkemotorer
Siden har sidetitler, beskrivelser, semantisk HTML, bildebeskrivelser og strukturert bedriftsinformasjon. sitemap.xml bruker den publiserte forhåndsvisningsadressen. Oppdater adressene der til endelig domene ved overtakelse. Ingen rangering er garantert.
